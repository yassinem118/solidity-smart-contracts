# 🚀 Solidity & Web3 Fundamentals

Welcome to my Solidity learning repository! This repository contains a collection of smart contracts written during my Web3 development journey.

## 📜 Contracts Overview

Here are the smart contracts included in this repository, written and tested using **Remix IDE**:

* **`counter.sol`**: A foundational contract demonstrating state modification (`increment`), getters, and the `external` visibility specifier.
* **`datatype.sol`**: Examples of primary value types in Solidity (integers, booleans, addresses).
* **`function.sol`**: Demonstrating the difference between `view`, `pure`, and state-modifying functions.
* **`variable.sol`**: State variables vs local variables vs global variables.
* **`default.sol`**: Default values for uninitialized variables in Solidity.

## 🛠️ Tools & Environment
